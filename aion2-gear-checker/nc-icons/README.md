# AION 2 – Originalgrafiken der Daevanion-Tafeln

Die unter `nc-icons/skills/` gespeicherten 35 Kleriker-Skillbilder und die fünf Rahmen in `nc-icons/frames/` stammen aus den Spielgrafiken von **NCSOFT Corporation**. © NCSOFT. Diese Bilder sind **nicht** unter der Open-Source-Lizenz des restlichen Fanprojekts veröffentlicht.

Die Quelldateien wurden aus dem öffentlichen Repository [austinsc/aion2-planner](https://github.com/austinsc/aion2-planner) übernommen. Die dortige [NOTICE.md](https://github.com/austinsc/aion2-planner/blob/main/NOTICE.md) dokumentiert Metabot als Quelle der Skillbilder und Wikily als Quelle der Daevanion-Rahmen. Sie werden ausschließlich als Referenzbilder für den nichtkommerziellen Gear Checker eingesetzt. Rechteinhaber können eine Entfernung anfordern.

Der lokale Cache wird mit `cache-daevanion-art.py` erstellt und durch `.github/workflows/aion2-art-sync.yml` veröffentlicht. Es ist keine Verbindung zu einem fremden Bilderhost im Browser mehr erforderlich.

Eine Kleriker-Fähigkeit wird über ihre offizielle NCSOFT-Skill-ID einer Grafik `nc-icons/skills/<Skill-ID>.webp` zugeordnet. Die Boards behalten den tatsächlichen importierten Freischaltstatus bei.
