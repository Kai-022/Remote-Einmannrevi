# AION 2 EU – Daeva Gear Checker (Browser-Version)

Browserbasierter Gear- und Pet-Checker für Kleriker im PvE.

**Website (sofern GitHub Pages für main/root aktiv ist):**
https://kai-022.github.io/Remote-Einmannrevi/aion2-gear-checker/

## Bedienung
1. Website öffnen, Charaktername eingeben und Spielstil auswählen.
2. Ausrüstungsplatz auswählen, Itemnamen und Werte (je eine Zeile) eintragen.
3. Gear-Bewertung, Upgrade-Plan und alle fünf Pet-Spezies mit jeweils neun empfohlenen Slots anzeigen.
4. Eingaben werden ausschließlich lokal im Browser gespeichert.
5. Über „Demo ansehen“ ohne Eingaben testen.

## Wichtige Einschränkung
**Automatischer Charakterimport ist in der statischen GitHub-Pages-Version nicht verfügbar.**
Die frühere lokal ausführbare Version verwendet einen Node.js-Proxy für NCSOFT-Endpunkte. GitHub Pages kann keine Node.js-Backend-Anwendung ausführen. Ein Online-Proxy oder Serverless-Endpunkt wäre ein gesonderter nächster Schritt. Kein Spiel-Login und keine Zugangsdaten erforderlich.

Dieses Fanprojekt ist nicht mit NCSOFT verbunden; Empfehlungen sind keine verifizierte Best-in-Slot-Simulation.
